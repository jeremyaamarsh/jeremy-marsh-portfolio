# MLB Attendance Analysis

## Project Overview
This project analyzes Los Angeles Dodgers home game attendance using exploratory data analysis (EDA). The dataset includes game-level attributes such as opponent, day of week, temperature, weather conditions, and promotional events. The goal is to identify factors that influence attendance and provide actionable insights.

## Goals and Objectives
- Examine patterns in attendance across the 2022 season  
- Identify variables that correlate with higher or lower turnout  
- Provide simple, data-driven insights to support attendance improvement  

## Techniques and Technologies Used
- Python  
- Pandas for data ingestion and exploration  
- Matplotlib and Seaborn for visualization  
- Jupyter Notebook for analysis workflow  

## Summary of Conclusions
- Attendance varies significantly by day of week and opponent  
- Promotional events (fireworks, bobbleheads) correlate with higher turnout  
- Temperature and weather show mild but noticeable effects  
- Scheduling and promotions appear to be meaningful drivers of attendance
